The JSON configuration is a synthetic version 1 migration fixture, not a personal configuration.

The USB text files contain only twelve-byte input reports from a Pilot Pro, one hexadecimal report per line. Timestamps, device identifiers, application state, local paths and diagnostic headers have been removed. Session A was recorded while the official main application was running; session B while its main process was closed. They exercise the joystick, wheels, simultaneous button states and non-action status reports without requiring hardware during tests.
